Smart Traffic Signal System — Mathematical Formulation & OpenCV CV Pipeline

1. Academic Abstract

Urban traffic congestion leads to substantial economic loss, fuel wastage, and elevated environmental emissions. Conventional fixed-time signal controllers allocate pre-determined phase durations that fail to adapt to asymmetric, dynamic traffic demand. This research presents SignalSync, an end-to-end Computer Vision-driven adaptive traffic signal control platform combining OpenCV background subtraction (MOG2), contour-based Passenger Car Unit (PCU) classification, and dynamic anti-starvation queuing optimization with multi-junction green wave corridor synchronization.

2. Mathematical PCU Formulation & Anti-Starvation Allocation

PCU_{lane} = 0.5 \times N_{bike} + 1.0 \times N_{car} + 3.0 \times N_{heavy}
Priority_i = Density_i \times \left(1 + \alpha \times \frac{Wait_i}{T_{starve}}\right) \times Boost_{starve}
T_{green, i} = \max\left(T_{min}, \min\left(T_{max}, \frac{PCU_i}{\sum PCU} \times Budget_{cycle}\right)\right)

3. 8-Step Computer Vision & Control Pipeline

  1. Video Capture: Ingests multi-camera perspective RTSP streams or uploaded MP4 traffic feeds.
  2. Spatial Preprocessing: Aspect normalization, Grayscale conversion, and 5×5 Gaussian smoothing.
  3. MOG2 Background Subtraction: Dynamic mixture of Gaussians with shadow suppression and morphological opening.
  4. Contour & Centroid Tracking: Area-bounded contour extraction, Euclidean centroid assignment, velocity calculation.
  5. Green Allocation: Real-time PCU weighting and anti-starvation boost with configurable bounds.
  6. Safe Sequencing: Inter-phase yellow transition, all-red clearance, and yellow-box gridlock protection.
  7. HMI Visualization: Cyberpunk-styled real-time telemetry, 2D junction physics, and approach camera overlays.
  8. Evaluation & Eco KPI: Idling vehicle-seconds reduction, saved fuel calculation, and CO2 abatement telemetry.

# SignalSync Production Python Implementation
import cv2
import numpy as np

def allocate_adaptive_green(pcus, t_min=10, t_max=45, budget=90):
    total = sum(pcus.values()) or 1.0
    allocations = {}
    for d, pcu in pcus.items():
        raw = (pcu / total) * budget
        allocations[d] = max(t_min, min(t_max, round(raw)))
    return allocations

# OpenCV MOG2 Tracking Pipeline
def process_traffic_frame(frame, bg_sub):
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)
    mask = bg_sub.apply(blur)
    _, mask = cv2.threshold(mask, 200, 255, cv2.THRESH_BINARY)
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (4, 4))
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel, iterations=2)
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    return contours
